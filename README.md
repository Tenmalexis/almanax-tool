## 📌 C'est quoi ?

L'Almanax est un système de quêtes journalières dans Dofus — chaque jour, un offrande différente est demandée en échange d'un bonus (XP, drop, kamas, stats...). Cet outil permet de **visualiser tous les Almanax du mois**, de **cocher ceux qui t'intéressent** selon le type de bonus, et de **planifier ta semaine** en conséquence.

---

## ✅ Fonctionnalités

- 📅 **Vue mensuelle complète** — tous les jours du mois avec la ressource à apporter, la quantité et le bonus associé
- ☑️ **Système de mentions** — coche les jours que tu veux retenir (bonus XP, drop, kamas, etc.) pour les mettre en évidence
- 📊 **Statistiques en temps réel** — nombre de jours chargés, jours mentionnés, pourcentage de complétion
- 📥 **Export CSV** — exporte le mois en fichier Excel pour avoir ta planification hors ligne
- 📝 **Générateur de script vidéo** — génère automatiquement un script YouTube à partir des almanax mentionnés
- 💾 **Sauvegarde locale** — tes mentions sont sauvegardées automatiquement dans ton navigateur
- 🗑️ **Effacer les sauvegardes** — repart de zéro en un clic

---

## 🚀 Comment utiliser

1. **Ouvre l'outil** via le lien ci-dessus
2. **Sélectionne le mois** que tu veux consulter
3. Clique sur **"Charger le mois"** — les données sont récupérées en direct depuis l'API Almanax
4. **Parcours la liste** des jours avec leur ressource, quantité et bonus
5. **Coche la colonne 📌 Mentionner** sur les jours qui t'intéressent (ex: bonus XP, drop rare, kamas)
6. Tes sélections sont **sauvegardées automatiquement**
7. Utilise **Export CSV** pour ouvrir dans Excel ou **Générer script vidéo** pour ta prochaine vidéo

---

## 🎯 Exemples d'utilisation

- Tu veux savoir **quels jours du mois ont un bonus XP** → filtre et coche uniquement ceux-là
- Tu prépares une **vidéo YouTube sur les meilleurs Almanax** → génère le script en un clic
- Tu veux **planifier tes sessions de jeu** sur les jours les plus rentables → exporte en CSV et organise ton agenda

---

## 🔧 Données

Les données Almanax sont récupérées en temps réel via l'**API DofusDB** — elles sont donc toujours à jour avec le jeu.
